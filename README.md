# Credit Card UI (Static)

## 📌 Objective
This project is a static credit card user interface built using HTML and CSS.  
The goal is to practice layout structuring and visual styling.

---

## 🚀 Features
- Credit card layout design
- Background image styling
- Display of card number, name, and expiration date
- Use of Flexbox for layout alignment
- Clean and minimal UI structure

---

## 🛠 Technologies Used
- HTML5
- CSS3 (Flexbox)
- Google Fonts (Poppins)

---

## 📚 What I Learned
- Structuring a simple UI component using HTML
- Applying background images and styling
- Using Flexbox for alignment and spacing
- Managing typography and layout consistency

---

## ⚠️ Limitations
- No responsiveness (layout may break on smaller screens)
- No interactivity (purely static UI)
- No animations or transitions
- Static data (no dynamic input or updates)
- No accessibility considerations

---

## 🔧 Future Improvements
- Add responsiveness with media queries
- Implement interactivity using JavaScript
- Allow dynamic data input (e.g., user typing card details)
- Add animations or hover effects
- Improve semantic HTML and accessibility
